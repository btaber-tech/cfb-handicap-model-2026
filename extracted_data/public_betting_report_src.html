How this is captured: VegasInsider.com (Better Collective, same network as Action Network) gates all but one "featured" game's bet/money percentages behind a free account. This dataset was captured manually via an authenticated browser session on 2026-08-20 — it is not yet an automated recurring capture the way line_snapshots_2026.csv is (that runs unattended every 6 hours locally). Turning this into a real weekly time series needs a session-based capture design, which is a follow-up, not done here.

RLM definition used: the spread moving in the direction the minority of bets (ticket count, not dollars) would want — the standard textbook definition. Money% is shown alongside as the usual explanation (fewer, larger bets outweighing more numerous small ones), not as the trigger condition itself.

Data: VegasInsider.com public betting percentages; CollegeFootballData.com /lines (Bovada, DraftKings) for real spread movement.
